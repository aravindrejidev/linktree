How this works (read once)
  1. Load: upload the index.html that's currently live on your GitHub repo.
  2. Edit: change your profile, add/remove projects, edit tech tags — the preview below updates instantly.
  3. Download: click "Download index.html" to get the updated file.
  4. Upload: replace the old index.html in your GitHub repo with this new one (and upload any new logo images you referenced). GitHub Pages updates within a minute.

This tool doesn't connect to GitHub or store anything anywhere online — it only reads the file you upload and prepares a new one for you to download. Nothing changes on your live site until you re-upload the downloaded file yourself. Your in-progress edits are auto-saved in this browser, so refreshing won't lose your work.
